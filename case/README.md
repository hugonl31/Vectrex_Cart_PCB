A two-part shell for the boards in this repository (they all share one outline), shaped after the
original Vectrex cartridges: the grip ribs on the sides, the arrow and the slot opening for the edge fingers.

| File | |
|---|---|
| `Vectrex_case_M3_top.stl` | the top half (74.8 x 72 x 16 mm) |
| `Vectrex_case_M3_bottom.stl` | the bottom half (74.8 x 72 x 13 mm) |
| `interface_test.stl` | a 1 mm test plate with the board's outline (54 x 41 mm): print it first to check the fit |

**Assembly:** the board's mounting holes sit on the shell's locating pins, and the halves close with one
**M3 screw** into an **M3 heat-set threaded insert** (the open render above shows both).

Print both halves flat, outside down. The renders show a translucent red filament - any colour works.
